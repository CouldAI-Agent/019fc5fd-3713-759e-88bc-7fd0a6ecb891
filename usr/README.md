# Addicen Coding

A polished, multi-platform educational coding application built with Flutter.

## Overview
Addicen Coding is designed to help users master programming concepts through learning paths, coding challenges, and progress tracking. It features a modern, responsive layout that adapts seamlessly to mobile, tablet, desktop, and web environments.

## Features
- **Responsive Dashboard**: Track progress and discover recommended learning paths.
- **Cross-Platform Navigation**: Mobile bottom navigation and desktop navigation rail.
- **Course Library**: Browse and enroll in various programming courses (Flutter, Python, Web, etc.).
- **Interactive Challenges**: Practice coding skills with hands-on challenges.
- **Dark/Light Mode**: Full Material 3 theme support adapted to system preferences.

## Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **Design System**: Material 3

## Setup & Run
1. Ensure Flutter is installed on your machine.
2. Run `flutter pub get` to fetch dependencies.
3. Start the application using `flutter run`.
